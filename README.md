# Złota Rączka

## Instrukcja działania aplikacji

1. **Instalacja zależności**
   - Przejdź do folderu `server` i uruchom `npm install`.
   - Przejdź do folderu `client` i uruchom `npm install`.

2. **Uruchomienie backendu**
   - Przejdź do folderu `server`.
   - Uruchom serwer komendą: `npm run dev` lub `npm start` (w zależności od konfiguracji).

3. **Uruchomienie frontendu**
   - Przejdź do folderu `client`.
   - Uruchom aplikację komendą: `npm run dev`.
   - Domyślnie aplikacja powinna być dostępna pod adresem `http://localhost:5173`.

4. **Opis działania**
   - Aplikacja składa się z części frontendowej (React/Vite) oraz backendowej (Node.js/Express).
   - Frontend komunikuje się z backendem za pomocą API.
   - Szczegółowe informacje o funkcjonalnościach znajdują się w kodzie źródłowym oraz komentarzach.

5. **Testowanie**
   - Testy jednostkowe i integracyjne można uruchomić odpowiednimi komendami w folderach `client` i `server` (np. `npm test`).

---

W razie problemów sprawdź logi w folderze `server/logs` lub skontaktuj się z autorem projektu.
